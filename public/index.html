Connexion à WhatsApp

Comment se connecter :

  1. Entrez votre numéro WhatsApp avec l'indicatif du pays (sans "+", sans parenthèses, sans espaces)
  2. Cliquez sur "Demander le code d'appairage"
  3. Copiez le code à 8 chiffres
  4. Ouvrez WhatsApp → Paramètres → Appareils liés → Lier un appareil
  5. Collez le code lorsque vous y êtes invité
